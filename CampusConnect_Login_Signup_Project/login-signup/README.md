## Project Description
CampusConnect is an original student-portal-themed front-end interface that demonstrates a responsive login and registration experience. It is built with Bulma CSS, custom CSS, HTML, and pure JavaScript. It is a class demonstration only and does not connect to a backend or database.

## Technologies Used
- HTML5
- Bulma CSS (via CDN)
- Custom CSS
- Pure JavaScript

## Implemented JavaScript Features
- Login form validation for identity and password fields
- Sign-up validation for name, email, username, password, and terms checkbox
- Password and confirm-password matching
- Show/hide password buttons
- Dynamic password strength indicator
- Success and validation notifications
- Prevents default form submission when fields are invalid
- Help link displays an informational notification

## How to Run
1. Download or clone the repository.
2. Keep the folder structure unchanged.
3. Open `index.html` in a modern browser.
4. Select **Create an account** to open the sign-up page.

An internet connection is needed to load Bulma CSS and Google Fonts from their CDNs.

## Important Note
This is a front-end-only school project. The success messages do not mean a real user was authenticated or registered. No credentials are transmitted or stored.
